# Anti-Corruption / Public Integrity Investigator

[English README](./README.md)

一个基于公开信息（OSINT）的公共廉政调查 Agent Skill，用于研究政府官员、公职人员、国企、城投、公共项目、政府采购、土地和企业之间**可验证的公开关系**，并识别值得进一步核查的廉政风险信号。

> 这个项目不是“AI 判官”，也不是用搜索结果给任何人贴上“腐败”标签。
>
> 它的目标是：**把公开、分散、难以人工审计的信息，整理成可核验、可追溯、带时间轴的证据图谱。**

## 怎么使用

安装后不用记命令，直接正常描述你的调查目标即可。例如：

```text
调查安徽省阜阳市某位政府官员，建立完整任职时间轴、权力地图、
公开关系图谱、项目和企业网络，并检查是否存在值得进一步核查的公开信息异常。
要求区分事实、异常信号和未验证假设，并主动寻找反证。
```

或者从一个已经公开的案件向外扩展：

```text
某干部刚被纪委通报接受调查。确认其过去十年的任职经历，
然后沿其主管项目、政府采购、工程项目、国企/城投、企业关系和正式领导链展开调查。
所有关系都必须有时间范围和公开证据，不能因为上下级关系直接推断领导存在问题。
```

## 它能做什么

Skill 会按照下面的流程研究：

1. **身份确认**：确认姓名、职务、任职时间，过滤同名误匹配。
2. **任职时间轴**：梳理工作经历和权力窗口。
3. **权力地图**：分析任期内可能影响的部门、项目、国企和政策领域。
4. **公开关系图谱**：构建“人—组织—企业—项目—合同—土地—案件”的时间关系图。
5. **Follow the Money**：追踪政府采购、公共资源交易、土地、城投融资和国企投资。
6. **异常信号检测**：识别重复中标、采购集中、企业随任职地迁移、关联投标、项目异常变更等模式。
7. **反证搜索**：主动寻找正常商业解释、历史原因和能够否定怀疑的证据。
8. **证据账本**：重要结论必须保留来源、日期、证据等级和置信度。

## 核心原则

### 不做“有罪推定”

下属落马、同事被查、企业反复中标、经常共同参加活动，都**不能自动推出某个官员存在腐败问题**。

项目强制区分：

- **已确认事实**
- **值得进一步核查的异常信号**
- **尚未验证的假设 / 未回答问题**

### 关系必须有类型，也必须有时间

`WORKED_WITH` 不等于 `RELATIVE_OF`；`ATTENDED_WITH` 不等于 `BUSINESS_PARTNER_OF`。

一个项目如果发生在官员到任前或离任后，相关性就必须显著降低。

### 主动寻找反证

调查不能只收集支持怀疑的信息。例如：

- 企业在干部到任之前已经进入当地；
- 公司在该干部到任前已经成立；
- 下属的关键提拔发生在前任领导时期；
- 某大型项目其实来自省级、市级统一规划。

这些都应降低风险信号的权重。

## 证据等级和异常信号

证据分为：

- **A — 一级权威来源**：纪检监察、法院、检察院、政府、审计、登记机关、采购和公共资源交易平台等。
- **B — 强二级来源**：可靠媒体对一级事实的转载或独立核实。
- **C — 可用线索**：公司公告、行业媒体、地方门户、历史存档等。
- **D — 未验证线索**：论坛、社交媒体、匿名爆料、聚合转载等。

Skill 当前包含 12 类典型风险信号，包括采购集中、到任后合同加速、Network Migration / Following Network、名义竞争者关联、项目变更异常、土地项目关联、城投/国企交易集中、人事商业时间重叠、同链条多人被查、审计问题反复出现、公开数据矛盾、高频接触后发生重大交易等。

**这些全部只是研究优先级信号，不是违法违纪结论，也不是“腐败概率”。**

## 案例：赵群公开信息研究

仓库包含一个完整案例：[`cases/zhao-qun/`](./cases/zhao-qun/)。

研究起点来自 2026 年 8 月，安徽省阜阳市颍东区政协原秘书长宫亚南被公开通报接受纪律审查和监察调查。

由此产生了一个研究想法：

> 从已经落马的干部开始，沿正式组织关系向上游做一次线性外推，看看公开信息能够发现什么。

于是选择其长期所在颍东区的区委书记赵群作为测试对象。

**这只是选题方法，不构成任何关于赵群存在违法违纪问题的暗示或指控。**

案例最终的严谨结论是：

> **截至研究日期，在所覆盖的公开资料范围内，未发现足以支持赵群本人存在违法违纪、私人利益输送或与宫亚南案件存在直接联系的可验证公开证据。**

这里的“未发现”绝不等于“证明不存在”。这个案例被保留在仓库里，恰恰是为了展示：一个调查 Agent 必须允许最后得到“没有足够证据”的结果，而不是从最初的怀疑出发一路制造 confirmation bias。

## 一点倡议：让“公开”真正变成可以被监督的公开

这个项目越往下做，越能感受到一个现实问题：很多时候，真正限制公众监督能力的并不是“没有人愿意查”，而是**依法可以公开、应当公开、适合公开的数据仍然太少、太碎、太难验证，也太难让机器读取。**

因此，我们希望各级政府、公共机构和国有企事业单位，在保护国家秘密、合法商业秘密和必要个人隐私的前提下，进一步扩大公共信息披露的范围与质量。

我们尤其希望更多公开：政府采购和招投标的完整数据，重大项目从立项、概算、预算、合同、变更到竣工决算和绩效结果的全过程信息，土地出让和规划调整，财政补贴与产业扶持，招商协议中依法可以公开的部分，地方国企和城投平台的投资、担保、关联交易、资产划转与重大资金往来，以及审计、巡视、巡察和财政监督发现问题后的整改结果。

更重要的是，**“有公示”不应该等于“完成监督”。**

我们也呼吁纪检监察、审计、人大监督、财政监督和其他有权审查机构进一步加强对公开信息本身的核验：不仅检查“有没有公开”，也检查公开的信息是否：

1. **完整**：依法应该公开的数据是否全部公开，有没有选择性遗漏。
2. **真实**：公开数据是否与原始账目、合同、登记记录和实际情况一致。
3. **一致**：不同部门、不同年份、不同文件之间是否出现无法解释的矛盾。
4. **可追溯**：数据、项目和资金用途发生修改后，是否保留完整历史版本。

我们希望未来的政府信息公开能够从：

> **“网页上曾经放过一个 PDF”**

逐渐走向：

> **结构化、机器可读、可检索、可批量下载、长期保存历史版本，并具有可靠时间戳或签名的公共数据基础设施。**

在 Agent 时代，每个普通人都可能拥有一个替自己阅读数万份预算、合同、公告、审计报告和企业登记的智能助手。监督的认知成本会越来越低；届时真正关键的问题将是：**公众有没有足够的数据可以监督？公开数据有没有人负责验证？发现矛盾以后有没有正式、可追踪的质询和纠错机制？**

更高质量的公开不仅保护公众，也保护认真履职的公职人员。事实越透明，越能减少谣言、猜测和“靠关系联想定罪”的空间。

**透明不是为了默认任何人有罪，而是为了让事实本身更容易被证明。**

## 免责声明

1. 所有研究仅使用合法公开信息。
2. 项目不获取、不披露家庭住址、私人电话号码、未成年子女学校、私人账户等不必要的敏感个人信息。
3. 某人被调查、处分或判刑，只能证明权威机关公开确认的具体事实，不应无限扩展到其领导、同事、亲属或商业接触对象。
4. 公开信息往往不完整，搜索不到并不代表事实不存在。
5. 新闻报道、企业宣传稿和搜索结果可能存在错误，重要结论应尽量回到政府、司法、纪检、交易平台、企业登记、审计和证券披露等一级来源。
6. “异常信号”只用于决定下一步研究方向，不代表违法、违纪、腐败、围标、利益输送或其他不当行为已经成立。
7. 对任何自然人的负面结论，都应以纪检监察、司法机关或其他有权机构的正式认定为准。
