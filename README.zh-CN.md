# Anti-Corruption / Public Integrity Investigator

[English README](./README.md)

一个基于公开信息（OSINT）的公共廉政调查 Skill，用于研究政府官员、公职人员、国企与公共项目之间可验证的公开关系，并识别值得进一步核查的廉政风险信号。

> 这个项目不是“AI 判官”，也不是用搜索结果给任何人贴上“腐败”标签。
>
> 它的目标是：**把公开、分散、难以人工审计的信息，整理成可核验、可追溯、带时间轴的证据图谱。**

## 它能做什么

你可以输入：

- 某位政府官员姓名；
- 某个职位，例如“安徽省阜阳市颍东区委书记”；
- 某个已经公开接受审查调查的干部；
- 某个政府项目、城投公司、国企或中标企业。

Skill 会按照下面的流程研究：

1. **身份确认**：确认姓名、职务、任职时间，避免同名误匹配。
2. **任职时间轴**：梳理过去的工作经历与权力范围。
3. **权力地图**：分析其任期内可能影响的部门、项目、国企和政策领域。
4. **公开关系图谱**：构建“人—组织—企业—项目—合同—土地—案件”的关系图。
5. **Follow the Money**：追踪政府采购、公共资源交易、土地、城投融资和国企投资。
6. **异常信号检测**：识别重复中标、采购集中、企业随干部任职地迁移、关联投标、项目异常变更等模式。
7. **反证搜索**：主动寻找正常商业解释、历史原因和能够否定怀疑的证据。
8. **证据账本**：所有重要结论都必须保留来源、日期、证据等级和置信度。

## 核心原则

### 1. 不做“有罪推定”

下属落马、同事被查、企业反复中标、经常一起出席活动，都**不能自动推出某个官员存在腐败问题**。

项目会强制区分：

- **已确认事实**
- **值得进一步核查的异常信号**
- **尚未验证的假设 / 未回答问题**

### 2. 关系必须有类型

例如：

- `WORKED_WITH`：工作交集
- `LED`：领导关系
- `WON_CONTRACT`：中标关系
- `SHAREHOLDER_OF`：股权关系
- `ATTENDED_WITH`：共同出席公开活动

`ATTENDED_WITH` 绝不等于 `BUSINESS_PARTNER_OF`，更不等于私人利益关系。

### 3. 时间必须对得上

一个项目发生在官员到任之前，或者发生在离任之后，相关性就应该显著降低。

因此关系图不是简单的：

```text
A —— B
```

而应当是：

```text
A —— B
   2022-2025
```

### 4. 主动寻找反证

调查不能只收集支持怀疑的信息。

例如：

- 某企业在干部到任前就已进入当地；
- 某公司早于该干部到任成立；
- 某下属的提拔发生在前任领导时期；
- 某大型项目其实是省级或市级统一规划项目。

这些都会降低某条风险信号的权重。

## 重点数据源

项目优先使用中国大陆公开可访问的数据：

- 中央纪委国家监委、各级纪委监委；
- 各级政府官网、组织部门任免公示；
- 中国政府采购网；
- 全国公共资源交易平台及地方交易平台；
- 国家企业信用信息公示系统；
- 中国土地市场相关公开信息；
- 全国建筑市场监管公共服务平台（四库一平台）；
- 审计署及地方审计部门；
- 上交所、深交所及债券发行/评级文件；
- 法院、检察院公开信息；
- 上市公司公告和高可信企业公开文件。

详见：[`skill/references/data-sources.md`](./skill/references/data-sources.md)

## 风险信号

当前 Skill 包含的典型信号包括：

- **S1 采购集中度异常**
- **S2 官员到任后企业合同显著增长**
- **S3 Network Migration / Following Network**：企业或关系网络跟随干部任职地迁移
- **S4 名义竞争者存在股东、人员或地址交叉**
- **S5 项目反复变更、重新招标、成本异常增加**
- **S6 土地—项目—企业关联异常**
- **S7 城投 / 国企与少数交易对手高度集中**
- **S8 职业关系后来转化为政府商业交易关系**
- **S9 同单位或同项目链多人先后被查**
- **S10 审计问题反复出现但长期未整改**
- **S11 官方公开资料之间存在关键数据矛盾**
- **S12 高频官方接触 + 后续重大交易同时出现**

**这些全部只是研究优先级信号，不是违法违纪结论。**

## 案例：赵群公开信息研究

仓库包含一个完整的案例：

[`cases/zhao-qun/`](./cases/zhao-qun/)

### 为什么研究赵群？

研究起点来自 2026 年 8 月，安徽省阜阳市颍东区政协原秘书长宫亚南被公开通报接受纪律审查和监察调查。

由此产生了一个研究想法：

> 从已经落马的干部开始，沿组织关系向上游做一次线性外推，看看公开信息能够发现什么。

于是选择其长期所在颍东区的区委书记赵群作为一个测试对象。

**这只是选题方法，不构成任何关于赵群存在违法违纪问题的暗示或指控。**

### 案例结论

截至案例研究日期，在所覆盖的公开资料范围内：

> **未发现足以支持赵群本人存在违法违纪、私人利益输送或与宫亚南案件存在直接联系的可验证公开证据。**

这里的“未发现”也绝不等于“证明不存在”。

研究过程中确实发现了一些值得继续监督的**制度和治理层面信号**，例如：

- 颍东区省委巡视整改涉及招投标等重点领域；
- 区属城投与参股施工企业之间存在需要关注公平性披露的交易结构；
- 城投公司曾出现募集资金使用/披露前后口径不一致问题；
- 地方国资、项目融资和政府投资之间形成较复杂的资金网络。

但这些目前只能说明：

> **存在值得进一步核查的公共治理问题。**

不能据此推断赵群个人存在腐败问题。

## 一点倡议：让“公开”真正变成可以被监督的公开

这个项目越往下做，越能感受到一个现实问题：很多时候，真正限制公众监督能力的并不是“没有人愿意查”，而是**依法可以公开、应当公开、适合公开的数据仍然太少、太碎、太难验证**。

因此，我们希望未来各级政府、公共机构和国有企事业单位能够在保护国家秘密、商业秘密和必要个人隐私的前提下，进一步扩大公共信息披露的范围与质量。

我们尤其呼吁更多公开：

- 政府采购、招投标和重大项目的完整机器可读数据；
- 项目立项、概算、预算、合同、变更、竣工决算和绩效结果；
- 土地出让、规划调整、财政补贴、产业扶持和招商协议中的可公开部分；
- 地方国企、城投平台的投资、担保、关联交易、资产划转和重大资金往来；
- 官员依法应当公开的履历、分工、重大公共决策参与情况以及利益冲突申报信息；
- 审计、巡视、巡察、财政监督发现问题后的整改进度与最终结果；
- 已公开数据的历史版本、修改记录和稳定永久链接。

更重要的是，**“有公示”不应该等于“完成监督”。**

我们也呼吁纪检监察、审计、人大监督、财政监督和其他有权审查机构进一步加强对公开信息本身的核验：

> 不仅检查“有没有公开”，也检查**公开的内容是不是真的、全不全、准不准、及时不及时。**

一个理想的监督体系，应当至少回答四个问题：

1. **Completeness — 完整性**：依法应该公开的数据是否全部公开？有没有选择性遗漏？
2. **Authenticity — 真实性**：公开数据是否与原始账目、合同、登记记录和实际情况一致？
3. **Consistency — 一致性**：不同部门、不同年份、不同公开文件之间的数据是否相互矛盾？
4. **Traceability — 可追溯性**：数据被修改、项目被变更、资金用途被调整后，公众能否看到完整历史记录？

我们希望未来的政府信息公开能够进一步从：

> **“网页上放过一个 PDF”**

走向：

> **结构化、机器可读、可检索、可批量下载、带数字签名或时间戳、历史版本长期保存的公共数据基础设施。**

因为在 Agent 时代，公众监督最大的变化可能不是所有人突然拥有更多时间，而是每一个普通人都可能拥有一个能够替他阅读数万份预算、合同、公告、审计报告和企业登记的智能助手。

当监督的认知成本大幅下降后，真正重要的制度问题将变成：

> **公众有没有足够的数据可以监督？公开数据有没有人负责验证？发现矛盾以后有没有正式、可追踪的质询和纠错渠道？**

我们相信，更高质量的公开不仅保护公众，也保护认真履职的公职人员。事实越透明，越能够减少谣言、猜测和“靠关系联想定罪”的空间。

**透明不是为了默认任何人有罪，而是为了让事实本身更容易被证明。**

## 免责声明

本项目尤其强调以下几点：

1. 所有研究仅使用合法公开信息。
2. 项目不获取、不披露家庭住址、私人电话号码、未成年子女学校、私人账户等不必要的敏感个人信息。
3. 某人被调查、处分或判刑，只能证明权威机关公开确认的具体事实，不应无限扩展到其领导、同事、亲属或商业接触对象。
4. 公开信息往往不完整，搜索不到并不代表事实不存在。
5. 新闻报道、企业宣传稿和搜索结果可能存在错误，因此重要结论应尽量回到政府、司法、纪检、交易平台、企业登记、审计和证券披露等一级来源。
6. “异常信号”用于决定下一步研究方向，不代表违法、违纪、腐败、围标、利益输送或其他不当行为已经成立。
7. 对任何自然人的负面结论，都应以纪检监察、司法机关或其他有权机构的正式认定为准。

## 使用方式

在 ChatGPT 中安装 Skill 后，可以直接输入类似：

```text
调查安徽省阜阳市某位政府官员，建立完整任职时间轴、公开关系图谱、项目和企业网络，并检查是否存在值得进一步核查的公开信息异常。
```

也可以从案件反推：

```text
某干部刚被纪委通报接受调查，请确认其过去十年的任职经历，然后沿其主管项目、直接领导、政府采购、工程项目和企业关系展开公开信息调查。
```

## 项目目标

这个项目真正想探索的问题不是：

> “AI 能不能判断谁是腐败官员？”

而是：

> **如果每个人都有一个能够阅读数万份政府文件、采购公告、企业登记、审计报告和项目资料的 Agent，公众监督政府的认知成本能否大幅下降？**

AI 最适合做的是整理事实、发现异常、构建关系和提出下一步问题。

最终判断，应该留给人和有权机构。
